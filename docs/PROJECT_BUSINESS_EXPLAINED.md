# 产品边界

当前产品只处理只读知识问答。QQ / CLI 用户提问，Agent 自主改写和检索，根据文档证据回答。管理员通过后台或 CLI 导入文档和重建索引。

支持知识文档原件交付：清洗后的 Markdown 用于回答，学校原始 PDF / Word 通过同一文档 ID 关联，用户可在 QQ 索要最近引用文档的原件。管理员可以同时导入两份文件或为已有文档补传原件。

不包含班级事务、个人记录查询、预约或转发。管理员 QQ 3244104494 可通过独立入口预览、确认通知与定时提醒，全员通知逐个私聊全部 QQ 好友；知识问答 Agent 不执行通知操作。旧数据库中的业务数据只留存，不再由当前程序初始化或访问。具体规则见 [管理员通知说明](NOTIFICATIONS.md)。

架构及升级说明见 TECHNICAL_DOCUMENTATION.md。
