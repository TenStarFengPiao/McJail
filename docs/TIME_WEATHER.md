# 时间与天气工具

Agent 的工具包括 `get_current_time()` 和 `get_weather(city, district, day="today", province="")`，所有 QQ 用户与 CLI 问答均可查询。这些工具只有读取能力，和管理员通知的创建、确认、发送分离，共享现有每请求八次工具调用上限。

## 当前时间

“现在几点”“今天几号”“今天星期几”调用服务器系统时钟，返回北京时间（UTC+08:00）、日期、星期与 ISO 时间。读取发生在工具执行时，服务器本地时区为 UTC 也会正确转换；精度取决于服务器时钟同步。不会使用模型知识截止日期或旧聊天时间作为当前时间。

## 市区天气与降雨时段

例子：“郴州市苏仙区明天几点可能下雨？”或者“衡阳市蒸湘区今天下午会下雨吗？”

参数 `city` 和 `district` 都须明确，可从同一会话的明确历史地点理解追问；没有市区时先询问，不按管理员QQ号、学校默认位置或模型猜测补地点。`province` 用于同名地点消歧。当前定位支持中国行政区，区也可以是县。`day` 可为今天/明天/后天（或英文today/tomorrow/after_tomorrow）、ISO日期，查询范围为今天起七天。

Nominatim 使用 OpenStreetMap 的行政区数据核对市和区县，拒绝错误城市、同名模糊结果、非行政地点及无效坐标。直辖市同时核对行政代码。区县坐标在进程内缓存一天，最多256项；公共定位查询进程内串行且间隔至少一秒。Open-Meteo 查询实际坐标，使用 `Asia/Shanghai` 返回小时预报，不需要额外API密钥。公共服务不可用时明确报错，不回退到模型记忆。

每小时返回区间开始/结束、降水概率（%）、预计降雨量（mm）、预计总降水量（雨雪，mm）、温度（℃）及天气现象。服务提供的累计量表示时间戳前一小时，代码明确转成小时区间；例如08:00数据对应07:00至08:00，不能说成08:00精确开始下雨。查询今天时排除已结束区间，包含当天最后一小时。缺测保留为空，不替换成零；整段缺少有效降雨数据时停止给出结论。

回答应表述为“预计北京时间下午X至Y点可能下雨，降水概率X%”，并注明 Open-Meteo 预报。没有明显雨量时表述为“预报暂无明显降雨”，不能保证不会下雨。数据表示区县行政中心附近的网格，不能保证全区每一条街、未来某一分钟准确下雨。

## 内部来源信息

学校来源ID和版本仍保存在 `chat_turns.sources_json` 并由文件工具校验，普通助手历史只传入可读回答，不再拼接 `来源元数据：[]`。输出和旧历史读取还过滤独立的来源元数据JSON段落，避免模型模仿内部字段；正文中的正常说明保留。学校参考来源仍由服务端统一生成一次，时间和天气不会伪造学校来源。

天气缺少地点、定位失败、网络失败或返回数据格式异常时，返回明确提示，不保存假装成功的半轮记录。全部网络调用有超时和响应大小限制。离线测试覆盖真实 Agent 工具链、城市区县匹配、逐小时区间、空数据、网络异常和旧历史泄露，不向QQ实际发送消息。
